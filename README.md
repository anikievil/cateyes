# 代購貓 🐾

代購清單小幫手 — 純前端網頁 app，逛街打勾、對帳收款一站搞定。

## 功能

- **檔期管理**：一次代購行程開一個檔期，支援「我是代購」與「我是委託人」兩種角色（用詞自動切換：應收↔應付）
- **採買清單**：可按委託人或分類/店家分組，逛街時點狀態直接切換：待購買 → 已買到 / 缺貨 → 已寄出 → 已收款
- **代購費**：檔期可統一設定（每件固定金額或售價 %），單一商品也可個別覆寫
- **對帳總表**：按委託人彙總應收/已收，一鍵「複製對帳文字」貼到 LINE 收款；缺貨商品自動排除不計
- **截止收單日**：過期的檔期會標示「已截止」
- **備份/還原**：資料存在瀏覽器 localStorage，可下載 JSON 備份、跨裝置手動搬移

## 技術

純 HTML / CSS / Vanilla JS，無建置步驟，直接靜態部署（Netlify）。
資料層封裝在 `app.js` 的 `Storage` 物件，未來要接雲端同步只需替換該層。

| 檔案 | 用途 |
|---|---|
| `index.html` | 入口頁 |
| `style.css` | 樣式（手機優先、響應式） |
| `app.js` | 全部邏輯與資料層 |
